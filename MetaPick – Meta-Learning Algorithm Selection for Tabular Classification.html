The algorithm selection problem

No single classifier wins on every dataset. Picking the right one usually means hours of manual experiments.

🎲

Trial and error is costly

Training and tuning many models on every new dataset burns compute and time.

🧠

Expertise doesn't scale

Experienced practitioners pick well from intuition, but beginners and busy teams can't rely on it.

⚡

Meta-learning learns to learn

Past results on many datasets teach a model which algorithm fits which kind of data.

How the framework works

A meta-model is trained once on a large collection of datasets. After that, every new dataset gets a recommendation instantly.

1. Collect datasetsGather many tabular classification benchmarks, such as those on OpenML.
2. Extract meta-featuresSize, class balance, feature types, correlation, entropy, landmarkers.
3. Run algorithmsCross-validate candidate classifiers and record each score.
4. Train meta-modelLearn the link between dataset traits and the best-performing algorithm.
5. RecommendFor a new dataset, output a ranked list of algorithms.

Candidate algorithms and evaluation plan

The framework ranks these classifiers and is judged on how often its top picks match the true best.

AlgorithmStrong whenWeak when

Missing features and next steps

What this first version does not do yet, and how the full framework will close each gap.

High priority

Trained meta-model

The demo uses hand-written rules. The real system needs a meta-model trained on hundreds of benchmark datasets.

Added

Upload your own CSV

The demo now reads a CSV in your browser and fills the sliders from its profile.

High priority

Real benchmark results

No measured accuracy, top-k or regret numbers are shown yet. These come from cross-validated experiments.

Medium

Missing-value handling

Meta-features for datasets with many missing values, plus built-in imputation advice, are not covered.

Medium

Hyperparameter suggestions

It recommends the algorithm only. It does not yet suggest settings such as tree depth or learning rate.

Medium

Explainable recommendations

Users should see which dataset traits drove each pick, for example with SHAP.

Later

Landmarking features

Fast, simple models can run on a data sample to add stronger meta-features.

Later

Compare with AutoML

Benchmark the framework against brute-force search and tools such as Auto-sklearn or FLAML.

Later

Regression and multi-label tasks

The scope is tabular classification only. Other task types are future work.
